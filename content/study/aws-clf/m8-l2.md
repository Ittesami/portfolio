Data analytics services **collect, store, process, query and visualise** data. The exam tests whether you can match each step of a data pipeline to the right service.

## The services

| Service | What it does |
|---|---|
| **Amazon Athena** | **Serverless SQL** queries **directly on data in S3**; pay per query (per data scanned). No loading, no servers |
| **AWS Glue** | Serverless **ETL** (extract, transform, load) to clean and prepare data, plus the **Glue Data Catalog** (metadata about your data lake) |
| **Amazon EMR** | Managed **big-data frameworks**: Hadoop, Spark, Hive |
| **Amazon Kinesis** | Collect and process **real-time streaming** data (Kinesis Data Streams; **Amazon Data Firehose** loads streams into S3/Redshift) |
| **Amazon MSK** | Managed **Apache Kafka** for streaming |
| **Amazon Redshift** | **Data warehouse** (Module 7) |
| **Amazon QuickSight** | **Business intelligence dashboards** and visualisations (Q lets you ask questions in plain English) |
| **Amazon OpenSearch Service** | **Search**, log analytics and observability (Elasticsearch-compatible) |
| **AWS Lake Formation** | Build and **secure a data lake** on S3 quickly |
| **AWS Data Exchange** | Find and subscribe to **third-party data sets** |

## A typical pipeline

```
clickstream / IoT data
   → Kinesis (stream in real time)
   → S3 (data lake)
   → Glue (clean, transform, catalogue)
   → Athena or Redshift (query)
   → QuickSight (dashboards)
   → SageMaker AI (train models on it)
```

## Keyword matching

| The question says… | Answer |
|---|---|
| "SQL queries on data **in S3**", "serverless", "pay per query" | **Athena** |
| "**ETL**", "prepare and transform data", "data catalog" | **Glue** |
| "**Hadoop**", "**Spark**", "big data framework" | **EMR** |
| "**real-time streaming** data", "clickstreams", "IoT streams" | **Kinesis** |
| "**Kafka**" | **MSK** |
| "**dashboards**", "visualise", "business intelligence" | **QuickSight** |
| "**search**", "log analytics" | **OpenSearch Service** |
| "data warehouse" | **Redshift** |

## Exam trap

**Athena vs Redshift:** Athena queries files **where they sit in S3**, ad hoc and serverless, paying per query. Redshift is a full data warehouse you **load** data into, for heavy, repeated analytics.

## Check yourself

1. A company wants to run SQL queries on log files stored in S3 without loading them anywhere. Which service?
2. Which service processes real-time streaming data from thousands of devices?
3. Which service builds BI dashboards?

### Answers

1. Amazon Athena.
2. Amazon Kinesis.
3. Amazon QuickSight.
