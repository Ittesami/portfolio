The **AWS Well-Architected Framework** is AWS's set of best practices for building good cloud systems, organised into **six pillars**. Expect questions that describe a practice and ask which pillar it belongs to.

## Memory trick

**CRISPS**: **C**ost optimisation, **R**eliability, operational excellence (**I**mprove ops), **S**ecurity, **P**erformance efficiency, **S**ustainability.

## The six pillars

| Pillar | Goal | Key principles and examples |
|---|---|---|
| **Operational excellence** | Run and monitor systems; **continually improve** processes | Perform operations **as code** (IaC); make **frequent, small, reversible** changes; refine procedures often; anticipate failure; **learn from operational failures** |
| **Security** | Protect data, systems and assets | Strong **identity foundation** (least privilege); enable **traceability** (logging); apply security **at all layers**; automate security; protect data **in transit and at rest**; prepare for security events |
| **Reliability** | The workload does its job correctly and **recovers from failure** | **Automatically recover** from failure; **test recovery** procedures; **scale horizontally**; stop guessing capacity; manage change through automation; multi-AZ, backups |
| **Performance efficiency** | Use resources **efficiently** as demand and technology change | **Democratise advanced technologies** (use managed services); go global in minutes; use **serverless**; **experiment more often**; choose the right resource type |
| **Cost optimisation** | Deliver business value at the **lowest price** | Adopt a **consumption model**; measure efficiency; stop spending on undifferentiated heavy lifting; **analyse and attribute** spending (tags); right-sizing, Savings Plans, Spot |
| **Sustainability** | **Minimise environmental impact** | Understand your impact; **maximise utilisation**; use more efficient hardware and software; use managed services; reduce downstream impact |

Sustainability is the **newest** pillar (the sixth).

## Matching practices to pillars

| The question describes… | Pillar |
|---|---|
| Making small, frequent, reversible changes; ops as code | **Operational excellence** |
| Least privilege, encryption, logging everything | **Security** |
| Multi-AZ, automatic recovery, testing recovery | **Reliability** |
| Choosing the right instance type, using serverless, experimenting | **Performance efficiency** |
| Right-sizing, tagging costs, Spot Instances | **Cost optimisation** |
| Reducing energy use, maximising utilisation | **Sustainability** |

## AWS Well-Architected Tool

A **free** service in the console: answer questions about a workload, and it reviews it against the framework and gives you an **improvement plan**. **Lenses** add industry-specific guidance (e.g. Serverless, Machine Learning, Financial Services).
