AWS also **advises** you on how to improve your account, and **tells** you when its own services have problems that affect you.

## AWS Trusted Advisor

Checks your account against **AWS best practices** and gives recommendations, in categories:

| Category | Example check |
|---|---|
| **Cost optimisation** | Idle or under-used EC2 instances, unattached volumes |
| **Performance** | Over-used instances |
| **Security** | Open security-group ports, root account without MFA, public S3 buckets |
| **Fault tolerance** | Instances in only one AZ, missing backups |
| **Service limits (quotas)** | Close to hitting a service quota |
| **Operational excellence** | Operational best practices |

**Basic Support** gets the **core security checks** and service-quota checks. The **full set of checks** needs a higher support plan (Module 11).

Keyword: "**recommendations** to reduce cost, improve security and performance" → Trusted Advisor.

## AWS Health Dashboard

A **personalised view of AWS service events that affect your resources**: outages, degraded performance, scheduled maintenance (e.g. "your instance will be retired"). It also shows public service status for everyone.

Keyword: "Is an AWS outage affecting **my** resources?" → **Health Dashboard**.

## AWS Compute Optimizer

Uses **machine learning** to give **right-sizing** recommendations for EC2 instances, EBS volumes and Lambda functions: "this instance is over-provisioned, use a smaller type".

## Telling them apart

| Need | Service |
|---|---|
| Best-practice checks across cost, security, performance… | **Trusted Advisor** |
| AWS problems affecting my resources | **Health Dashboard** |
| Is this instance the right size? | **Compute Optimizer** |
