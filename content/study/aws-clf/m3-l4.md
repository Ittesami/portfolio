This lesson pulls Modules 2 and 3 together. Compute questions on the exam almost always follow the pattern **"a company needs X — which compute service?"**. Learn this table and you'll answer most of them.

## The decision table

| Requirement in the question | Answer |
|---|---|
| Full control of the operating system; long-running application | **Amazon EC2** |
| Short, event-driven code; no servers; pay per use | **AWS Lambda** |
| Containers without managing servers | **AWS Fargate** (with ECS or EKS) |
| Containers with Kubernetes | **Amazon EKS** |
| AWS's own container orchestration | **Amazon ECS** |
| "Just deploy my web app code"; AWS handles the infrastructure | **AWS Elastic Beanstalk** |
| Cheapest simple server with a fixed monthly price | **Amazon Lightsail** |
| Large numbers of batch jobs | **AWS Batch** |
| AWS services in my own data centre | **AWS Outposts** |
| Web app from source code or image, no infrastructure at all | **AWS App Runner** |

## How to think it through

Ask three questions, in order:

1. **Do they need control of the OS or the server?** → EC2.
2. **Is it containers?** → Kubernetes? EKS. No servers? Fargate. Otherwise ECS.
3. **Is it short code reacting to events?** → Lambda.

Then check for special words: "on-premises" → Outposts, "simple fixed price" → Lightsail, "upload code" → Beanstalk.

## The operational-overhead scale

From most work for you to least:

```
EC2  →  ECS/EKS on EC2  →  Elastic Beanstalk  →  Fargate / App Runner  →  Lambda
(you manage most)                                          (you manage least)
```

When the question says "**least operational overhead**", pick the option furthest to the right that still meets the requirements.

## Worked scenarios

> Process thousands of images uploaded each day; each takes 30 seconds; no servers to manage. → **Lambda** (short, event-driven).

> A video-rendering job runs for 6 hours. → **EC2** (or AWS Batch), because Lambda's limit is 15 minutes.

> A team's app is packaged in Docker containers and they don't want to patch servers. → **Fargate**.

## Check yourself

1. A job runs for 3 hours. Why isn't Lambda a good fit?
2. Which option has the least operational overhead for running containers?
3. What does the word "Kubernetes" in a question point to?

### Answers

1. One Lambda invocation can run for at most 15 minutes.
2. AWS Fargate (serverless containers).
3. Amazon EKS.
