Besides paid support plans, AWS has many **free** resources and **partner** options for getting help.

## Free self-help

| Resource | What it is |
|---|---|
| **AWS re:Post** | A community **Q&A forum** (like Stack Overflow for AWS), with answers from the community and AWS experts. Free |
| **AWS Knowledge Center** | Articles answering the most common questions and requests |
| **AWS documentation** | User guides and API references for every service |
| **Whitepapers** | In-depth guides, e.g. the Well-Architected Framework and security best practices |
| **AWS Prescriptive Guidance** | Proven strategies, patterns and guides for migrations and architectures |

## People who can help

| Option | What it is |
|---|---|
| **AWS Professional Services** | AWS's own consulting team for hands-on help with big projects |
| **AWS Partner Network (APN)** | Third-party **consulting partners** (who help you design, build, migrate) and **technology partners** (who sell software on AWS) |
| **AWS Solutions Architects / account teams** | AWS staff who guide larger customers on architecture |
| **Technical Account Manager (TAM)** | Part of Enterprise support (previous lesson) |

## Keyword matching

| The question says… | Answer |
|---|---|
| "community forum", "ask other users" | **AWS re:Post** |
| "find a third-party company to help migrate" | **AWS Partner Network** (consulting partner) |
| "AWS's own experts to deliver a project" | **AWS Professional Services** |
| "best-practice guides" | **Whitepapers**, **Prescriptive Guidance** |

## Check yourself

2. A company wants to hire an outside firm experienced with AWS migrations. Where should it look?

2. The AWS Partner Network (APN), for a consulting partner.
