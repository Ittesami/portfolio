All cloud storage falls into three types. Most storage questions on the exam are really asking: **which type does this workload need?**

## The three types

| Type | How data is stored | Behaves like | AWS services |
|---|---|---|---|
| **Block** | Split into fixed-size **blocks**; the OS sees a disk | A **hard drive** plugged into one computer | **Amazon EBS**, EC2 instance store |
| **File** | A hierarchy of **folders and files** | A **shared network drive** many computers use at once | **Amazon EFS**, **Amazon FSx** |
| **Object** | Each file is an **object**: the data + metadata + a unique key, in a flat **bucket** | Unlimited online storage accessed over HTTP | **Amazon S3** |

## Block storage

- Fast, low-latency, and you can change part of a file without rewriting all of it (only the changed blocks).
- Ideal for **operating systems, databases and applications** that need a "disk".
- Usually attached to **one instance** at a time.

## File storage

- Many servers can **read and write the same files at the same time**.
- Ideal for **shared content**: home directories, content management, shared code, media workflows.

## Object storage

- **Massively scalable** and very durable; you never run out of space.
- Changing an object means **replacing the whole object**, so it's not for databases or OS disks.
- Ideal for **backups, media, static websites, data lakes, logs, archives**.

## Choosing

| The question says… | Type | Service |
|---|---|---|
| "disk for an EC2 instance", "boot volume", "database storage", "low latency" | Block | EBS |
| "shared by many instances at once", "Linux file system", "NFS" | File | EFS |
| "Windows file shares", "SMB" | File | FSx for Windows File Server |
| "unlimited storage", "images and videos", "backups", "static website", "data lake" | Object | S3 |

## Check yourself

1. Which storage type should host a database running on EC2?
2. Ten Linux EC2 instances must read and write the same files at the same time. Which type and service?
3. Why isn't object storage good for a database's data files?

### Answers

1. Block storage (Amazon EBS).
2. File storage: Amazon EFS.
3. Changing an object means rewriting the whole object, while databases constantly change small parts of their files. Block storage can update just the changed blocks.
