Beyond EC2, Lambda and containers, AWS has several compute services aimed at **specific needs**. Each one is a likely exam answer when its keyword appears.

## AWS Elastic Beanstalk (PaaS)

You **upload your application code**; Beanstalk automatically handles **capacity provisioning, load balancing, Auto Scaling and health monitoring**. You still have full control of (and can see) the underlying resources if you need it.

Keyword: "**just deploy my web application** and let AWS handle the infrastructure". Beanstalk itself is free; you pay for the resources it creates.

## Amazon Lightsail

**Simple virtual private servers** (plus storage, databases and networking) for a **low, predictable monthly price**. Ideal for simple websites, blogs and small business apps, or for people new to the cloud.

Keyword: "**simple**", "**fixed monthly price**", "small website".

## AWS Batch

Runs **batch computing jobs** at any scale (thousands of jobs), automatically provisioning the right amount and type of compute. You submit jobs; Batch queues and runs them.

Keyword: "**batch jobs**", "hundreds of thousands of jobs", "scientific computing".

## AWS Outposts

**AWS-managed racks** of AWS infrastructure installed **in your own data centre**. You run AWS services on-premises with the same APIs and tools, for **very low latency** to on-premises systems or **data that must stay on-site**.

Keyword: "**AWS services on-premises**", "in our own data centre".

## AWS App Runner

Deploy **containerised web apps and APIs** directly from **source code or a container image**, with no infrastructure to configure at all. Even simpler than ECS + Fargate.

## Quick reference

| Service | One line |
|---|---|
| Elastic Beanstalk | Upload code, AWS runs the infrastructure (PaaS) |
| Lightsail | Simple servers at a fixed monthly price |
| AWS Batch | Run large numbers of batch jobs |
| Outposts | AWS infrastructure in your own data centre |
| App Runner | Web app/API from code or image, zero infrastructure |

## Check yourself

1. A blogger wants a simple server with a predictable monthly bill. Which service?
2. A developer wants to upload a web application and have AWS handle load balancing, scaling and monitoring. Which service?
3. A factory needs AWS services running inside its own building for very low latency. Which service?

### Answers

1. Amazon Lightsail.
2. AWS Elastic Beanstalk.
3. AWS Outposts.
