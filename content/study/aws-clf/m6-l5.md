**File storage** gives many servers a **shared** file system they can all read and write at the same time, like a network drive in an office. AWS has two families of managed file storage.

## Amazon EFS (Elastic File System)

- A fully managed, **elastic** shared file system for **Linux** (it uses the **NFS** protocol).
- **Many EC2 instances, across multiple Availability Zones**, can use it at once.
- **Regional:** your data is stored across AZs.
- **Grows and shrinks automatically** as you add and remove files: no capacity planning, and you pay for what you store.

```
EC2 (AZ a) ──┐
EC2 (AZ b) ──┼──→  Amazon EFS  (one shared file system)
EC2 (AZ c) ──┘
```

## Amazon FSx

Managed versions of popular **third-party file systems**:

| FSx flavour | Use for |
|---|---|
| **FSx for Windows File Server** | Windows file shares (**SMB** protocol), integrates with **Active Directory** |
| **FSx for Lustre** | **High-performance computing** and machine learning: very fast parallel access |
| **FSx for NetApp ONTAP** | Moving NetApp workloads to AWS |
| **FSx for OpenZFS** | ZFS-based workloads |

## EFS vs EBS (a classic pair)

| | Amazon EBS | Amazon EFS |
|---|---|---|
| Type | Block (a disk) | File (a shared file system) |
| Attached to | **One instance** (normally) | **Many instances** at once |
| Scope | **One AZ** | **Multiple AZs** (regional) |
| Size | You choose and pay for it | **Grows and shrinks automatically** |

## Worked scenarios

> Many Linux web servers in different AZs must share the same uploaded files. → **Amazon EFS**.

> A company moving Windows applications needs SMB file shares with Active Directory. → **FSx for Windows File Server**.

> A machine-learning team needs a very fast file system for training data. → **FSx for Lustre**.

## Check yourself

1. Which service gives Linux instances in several AZs a shared file system?
2. Which service provides Windows (SMB) file shares?
3. Name two differences between EBS and EFS.

### Answers

1. Amazon EFS.
2. Amazon FSx for Windows File Server.
3. Any two: EBS is block storage, EFS is file storage; EBS attaches to one instance, EFS to many; EBS is in one AZ, EFS spans AZs; EBS has a fixed size you provision, EFS grows and shrinks automatically.
