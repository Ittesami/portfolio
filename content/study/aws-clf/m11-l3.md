AWS has a whole family of cost tools. The exam's favourite trick is to mix up **when** each one is used: **before** you build, **looking back** at spend, or **alerting** on future spend.

## The classic trio

| Tool | When | Use it to… |
|---|---|---|
| **AWS Pricing Calculator** | **Before** you build | **Estimate** the cost of an architecture or a migration |
| **AWS Cost Explorer** | **Looking back** (and a short forecast) | **Visualise and analyse** past and current costs, by service, account or tag, up to 12 months back; forecasts; Savings Plan/RI recommendations |
| **AWS Budgets** | **Going forward** | Set cost or usage **budgets** and get **alerts** when you exceed, or are forecast to exceed, them; can also trigger actions |

Memory hook: **Calculator = before. Cost Explorer = past. Budgets = alerts.**

## The rest of the family

| Tool | Use it to… |
|---|---|
| **Billing and Cost Management console** (billing dashboard) | See the current bill, payments, invoices, Free Tier usage |
| **AWS Cost Anomaly Detection** | Get **ML alerts on unusual spending spikes** |
| **AWS Cost and Usage Report** (CUR, via Data Exports) | The **most detailed, line-item** billing data, delivered to S3 for your own analysis |
| **Cost allocation tags** | Tag resources (e.g. `Project=Portfolio`) to **break down costs by project or team** |
| **Consolidated billing** (Organizations) | One bill for many accounts; shared volume discounts and Savings Plan/RI benefits |
| **AWS Compute Optimizer** | Right-sizing recommendations |
| **AWS Marketplace** | Find, buy and deploy **third-party software** (AMIs, SaaS) that runs on AWS, billed through your AWS bill |

## Keyword matching

| The question says… | Answer |
|---|---|
| "estimate the cost before migrating" | **Pricing Calculator** |
| "analyse spending over the last few months", "which service costs most" | **Cost Explorer** |
| "notify me when costs go above $X" | **Budgets** |
| "unexpected spike in spending" | **Cost Anomaly Detection** |
| "most detailed billing data", "line items" | **Cost and Usage Report** |
| "costs per department/project" | **Cost allocation tags** |
| "buy third-party software that runs on AWS" | **AWS Marketplace** |

## Check yourself

1. A company wants an email when its monthly bill is forecast to exceed £500. Which tool?
2. A company wants to estimate the cost of moving its data centre to AWS. Which tool?
3. A finance team wants to see which service caused last month's increase. Which tool?

### Answers

1. AWS Budgets.
2. AWS Pricing Calculator.
3. AWS Cost Explorer.
