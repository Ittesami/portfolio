**Encryption** turns data into unreadable ciphertext that only someone with the right **key** can read. AWS gives you services to manage those keys, and to keep secrets like passwords out of your code.

## Two kinds of encryption

| | At rest | In transit |
|---|---|---|
| Protects | **Stored** data (disks, S3, databases) | Data **moving** across a network |
| How | Encrypting the storage (often with KMS keys) | **TLS/SSL** (HTTPS) |

## The services

| Service | What it does |
|---|---|
| **AWS KMS** (Key Management Service) | **Create and manage encryption keys**; integrated with most AWS services (S3, EBS, RDS…); you control **who can use** each key, and every use is logged in CloudTrail |
| **AWS CloudHSM** | **Dedicated hardware security modules**: single-tenant hardware where **you** fully manage the keys, for strict compliance requirements |
| **AWS Secrets Manager** | Store, retrieve and **automatically rotate secrets**: database passwords, API keys |
| **AWS Certificate Manager (ACM)** | Provision and **renew SSL/TLS certificates**, free for use with AWS services (load balancers, CloudFront) |

## KMS vs CloudHSM

- **KMS:** AWS-managed, multi-tenant, easy, integrated everywhere. The usual answer.
- **CloudHSM:** **dedicated** hardware, **you** control the keys entirely. The answer when the question stresses "**dedicated hardware**", "single-tenant", or strict regulatory key control.

## Never hard-code secrets

Putting a database password in your code (or on GitHub) is a classic mistake. Store it in **Secrets Manager**; your app fetches it at runtime, and Secrets Manager can **rotate** it automatically.

## Worked scenarios

> Encrypt data in S3 and control who can use the encryption keys. → **AWS KMS**.

> Store a database password securely and rotate it every 30 days automatically. → **AWS Secrets Manager**.

> Get a free TLS certificate for a website behind a load balancer. → **AWS Certificate Manager**.

## Check yourself

1. Which service automatically rotates database credentials?
2. Which service provides dedicated, single-tenant hardware for key storage?
3. What protects data in transit?

### Answers

1. AWS Secrets Manager.
2. AWS CloudHSM.
3. TLS/SSL encryption (e.g. HTTPS), with certificates from AWS Certificate Manager.
