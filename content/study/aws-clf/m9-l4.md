These services **block attacks** before they reach your application: floods of fake traffic (DDoS) and malicious web requests.

## DDoS attacks

A **distributed denial-of-service (DDoS)** attack floods your application with traffic from many machines so real users can't get through.

## The services

| Service | Protects against / does |
|---|---|
| **AWS Shield Standard** | **DDoS** protection for **all** AWS customers, **automatic and free** |
| **AWS Shield Advanced** | **Paid**, enhanced DDoS protection: 24/7 **Shield Response Team**, **DDoS cost protection** (credits if an attack drives up your bill), detailed diagnostics |
| **AWS WAF** | **Web application firewall**: filters HTTP(S) requests by rules: **SQL injection**, **cross-site scripting (XSS)**, blocking IP addresses or countries, **rate limits**. Works with CloudFront, Application Load Balancer and API Gateway |
| **AWS Firewall Manager** | **Centrally** manage WAF, Shield and security-group rules **across many accounts** |
| **AWS Network Firewall** | A managed network firewall for your **VPCs** |

## Shield vs WAF

- **Shield** handles **floods** of traffic (DDoS, mostly at the network level).
- **WAF** inspects **individual web requests** and blocks the bad ones (application level: SQL injection, XSS, bots).

They're often used together, in front of CloudFront or a load balancer.
