EC2 **instance types** are grouped into **families**, each tuned for a different kind of work. You don't need to remember instance names for the exam, but you **must** match a workload to the right family.

## The five families

| Family | Optimised for | Typical use | Example names |
|---|---|---|---|
| **General purpose** | A balance of compute, memory and networking | Web servers, code repositories, small databases | t3, m7 |
| **Compute optimised** | High-performance processors | Gaming servers, high-performance computing (HPC), batch processing, scientific modelling | c7 |
| **Memory optimised** | Large data sets **in memory** | In-memory databases, real-time big-data analytics | r7, x2 |
| **Accelerated computing** | GPUs and other hardware accelerators | Machine learning, graphics, video encoding | p5, g5, inf, trn |
| **Storage optimised** | High, fast reads and writes to **local** storage | Data warehouses, OLTP systems, distributed file systems | i4, d3 |

## How to choose (the exam pattern)

Look for the **bottleneck** in the question:

- "balanced", "a variety of workloads", "web server" → **general purpose**
- "CPU-intensive", "high-performance processors", "batch", "gaming servers" → **compute optimised**
- "large data sets in memory", "in-memory database", "real-time processing of big data" → **memory optimised**
- "machine learning training", "graphics", "GPUs", "floating-point calculations" → **accelerated computing**
- "high sequential read/write on local storage", "data warehouse", "high IOPS" → **storage optimised**

## Reading an instance name

`m7g.large`: **m** = family (general purpose), **7** = generation, **g** = an extra attribute (here, AWS Graviton processor), **large** = size. Bigger sizes (`xlarge`, `2xlarge`) mean more CPU and memory. You won't be tested on this, but it helps the names make sense.

## Worked scenario

> A company runs a real-time analytics application that loads very large data sets into memory.

The bottleneck is **memory**, so **memory optimised**.

## Check yourself

1. Which family suits a high-performance web gaming server that needs powerful CPUs?
2. Which family would you choose for training machine-learning models on GPUs?
3. A small company needs one instance for a web server, a code repository and a small database. Which family?

### Answers

1. Compute optimised.
2. Accelerated computing.
3. General purpose.
