Most AI libraries and research code are Python, and the ML module uses it. This is the toolkit you need to keep Python projects clean.

## Virtual environments

A **virtual environment** is a private folder of packages for one project, so projects don't fight over versions.

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows (PowerShell: .venv\Scripts\Activate.ps1)
source .venv/bin/activate     # macOS / Linux
pip install anthropic python-dotenv
pip freeze > requirements.txt # record exact versions
```

- Add `.venv/` to `.gitignore`. Rebuild elsewhere with `pip install -r requirements.txt`.
- **uv** (`pip install uv`, then `uv venv`, `uv pip install ...`) does the same, much faster. Worth switching to once the basics are familiar.

## Type hints

Python doesn't enforce types, but **hints** make code readable and let your editor catch mistakes.

```python
def cost(input_tokens: int, output_tokens: int, price_in: float = 4.0, price_out: float = 20.0) -> float:
    """Dollar cost; prices are per million tokens."""
    return input_tokens / 1e6 * price_in + output_tokens / 1e6 * price_out

from typing import Literal
Status = Literal["todo", "doing", "done"]
```

## Data classes and Pydantic

For structured data, use a **dataclass** (built in) or **Pydantic** (adds validation, used everywhere in AI code).

```python
from pydantic import BaseModel, Field

class Meal(BaseModel):
    name: str
    kcal: int = Field(ge=0)
    protein_g: float = Field(ge=0)

Meal.model_validate({"name": "Eggs", "kcal": 150, "protein_g": 12})   # ok
Meal.model_validate({"name": "Eggs", "kcal": -5, "protein_g": 12})    # raises ValidationError
```

Pydantic models can turn into **JSON Schemas** (`Meal.model_json_schema()`), which is exactly what tools and structured outputs need later.

## async: doing many calls at once

API calls spend most of their time **waiting on the network**. `async` lets one program wait on many at once.

```python
import asyncio
import anthropic

client = anthropic.AsyncAnthropic()

async def ask(q: str) -> str:
    r = await client.messages.create(
        model="claude-haiku-5-5", max_tokens=500,
        messages=[{"role": "user", "content": q}],
    )
    return r.content[0].text

async def main():
    questions = ["Define RAG in one line.", "Define an eval in one line.", "Define MCP in one line."]
    answers = await asyncio.gather(*(ask(q) for q in questions))   # all three run together
    for q, a in zip(questions, answers):
        print(q, "→", a)

asyncio.run(main())
```

Three sequential calls of 2 s each take 6 s; with `gather` they take about 2 s.

**Don't fire hundreds at once**: you'll hit rate limits. Cap concurrency with a semaphore:

```python
sem = asyncio.Semaphore(5)
async def ask_limited(q):
    async with sem:
        return await ask(q)
```

## Check yourself

1. Why use a virtual environment per project?
2. What does Pydantic add over a plain dictionary?
3. Five API calls take 3 s each. Roughly how long do they take with `asyncio.gather`?

### Answers

1. So each project has its own package versions and installing something for one project can't break another.
2. Validation (types, ranges, required fields) and automatic JSON Schema generation.
3. About 3 seconds (they wait on the network at the same time), assuming no rate limiting.
